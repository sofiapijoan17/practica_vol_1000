## Indicaciones generales

1. El examen es individual.
2. Debes completar el examen en un máximo de 120 minutos.
3. Podés utilizar cualquier libro, recurso en línea o código antiguo durante este examen, pero no puedes comunicarte con ninguna persona que no sean tus docentes.
4. Debes usar las funciones que vimos en clase, en el libro de la materia y en los ejercicios, siguiendo los consejos vistos en clase.
5. Si usás funciones que no vimos en clase o en el libro, agregá antes del chunk de código una breve explicación de por qué las elegiste (por ejemplo, por qué son una mejor opción que las vistas en clase).
6. Este examen parcial consta de varias tareas que debes completar. Cada tarea se describe en un chunk de código separado. Debes completar cada tarea en el chunk correspondiente.

## Instrucciones para trabajar

1. Vamos a utilizar GitHub para manejar el examen. Por favor, cloná este repositorio siguiendo las instrucciones que dejamos en el campus para comenzar a trabajar.
2. Abrí el proyecto de RStudio y luego los archivos .qmd contenidos en la carpeta consignas del proyecto.
3. Cuando termines, tendrás que hacer commit y push para que tus cambios sean enviados a GitHub Classroom.
4. Copiá el SHA del commit y envialo a través del campus siguiendo las instrucciones que dejamos ahí.
